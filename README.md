# ONFH_transcriptomic_analysis

This repository contains the analysis code used for the transcriptomic study of steroid-induced osteonecrosis of the femoral head (ONFH).

## Datasets

Publicly available GEO datasets were used in this study:

- GSE74089
- GSE345158

## Analysis workflow

The scripts include:

- Differential expression analysis
- Meta-analysis
- Tissue context analysis
- Cell composition analysis
- Doublet assessment
- Negative control analysis
- Signature validation
- Visualization


## Software

All analyses were performed using R.

The scripts provided here correspond to the analyses described in the manuscript and during the revision process.
